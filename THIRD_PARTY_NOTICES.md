# Third-party software

FlacSplitter uses third-party components under their own licenses:

- [PySide6 / Qt](https://doc.qt.io/qtforpython-6/licenses.html) — LGPL/GPL/commercial licenses.
- [Mutagen](https://github.com/quodlibet/mutagen) — comply with the bundled version's license.
- [PyInstaller](https://pyinstaller.org/en/stable/license.html) — GPL with a special exception.
- [FFmpeg](https://ffmpeg.org/legal.html) — terms depend on the binary build. The pipeline uses Gyan Doshi's Windows release-essentials build, which may trigger GPL redistribution duties (notices and corresponding source access).

Review exact versions and license terms before publishing releases.
