# FlacSplitter

Минималистичная программа для Windows 10/11 x64: разделение одного FLAC-альбома по файлу CUE с сохранением треков рядом с исходным CUE.

## MVP

- Открытие `.cue`, предварительный просмотр треков и выходных имён.
- Пользовательская маска имени файла из `config.json` рядом с EXE.
- Разделение одного исходного FLAC через FFmpeg с точными границами CUE и **lossless** кодированием FLAC.
- Теги и обложка исходного FLAC, UTF-8 и Windows-1251 в CUE.
- Без перезаписи существующих файлов.
- Портативная сборка Windows через GitHub Actions / PyInstaller, версия `0.1.<pipeline>`.

## Маска имени

По умолчанию: `%n. %a - %t`.

| Код | Значение |
| --- | --- |
| `%N` | Количество треков |
| `%n` | Номер трека (с ведущим нулём) |
| `%A` | Исполнитель альбома |
| `%a` | Исполнитель трека (или альбома) |
| `%T` | Название альбома |
| `%t` | Название трека |
| `%c` | Комментарий/описание альбома |
| `%y` | Год |
| `%g` | Жанр |
| `%%` | Символ `%` |

Запрещённые для Windows символы заменяются на `_`; корректные Unicode-символы, включая русский мягкий знак, не изменяются.

При первом запуске создаётся `config.json` возле исполняемого файла:

```json
{
  "filename_mask": "%n. %a - %t"
}
```

## Ограничения первой версии

CUE должен ссылаться на **один** существующий файл FLAC. Для треков используются метки `INDEX 01`; промежутки перед следующими треками относятся к предыдущим. В версии MVP не поддерживаются CUE с несколькими аудиофайлами, скрытые треки как отдельные файлы, редактирование тегов и пакетная обработка. Оригиналы никогда не изменяются.

Разделение производится через декодирование и повторное **lossless** кодирование FLAC. Это сохраняет аудиоданные, но не гарантирует побайтовую идентичность сжатого потока.

## Разработка

Для запуска на Windows необходим Python 3.13:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-build.txt
python main.py
python -m unittest discover -s tests -v
```

Разместите `ffmpeg.exe` рядом с `main.py` или в `PATH`. После CI сборки FFmpeg расположен рядом с EXE. Исходный код — MIT. Подробнее о сторонних лицензиях см. `THIRD_PARTY_NOTICES.md`.
